# GPTI repository instructions

Read `README.md`, `standards.lock.md`, `governance/status-register.md` and the relevant strategy/brand/website file before editing. Never infer legal formation, tax exemption, partner authorization or UN status from a proposed name or draft document.

## Word outputs

Use **Word Document Standard v1.1** pinned in `standards.lock.md`. Start with `sunshinerao/my-standards/prompts/word_AGENT_START.md`, then read the seven normative files it names at the pinned commit. Apply exact JSON tokens, render and inspect every page, record exceptions. Source Markdown is maintained beside each final Word deliverable.

## Website outputs

Use **Website Design System v1.0 — Platform mode**, pinned in `standards.lock.md`. Read root `README.md`, `AGENTS.md`, `web/01_GLOBAL_FOUNDATION.md`, `web/platform/DESIGN_SYSTEM.md`, `web/platform/INTERACTION_SYSTEM.md`, `web/AI_BUILD_RULES.md` and `web/REFERENCE_REGISTRY.md` from the standards repository before UI work. Do not replace normative tokens with recollections or design inspiration. Website requirements and content schema live in `website/`.

## Content controls

- Treat this repository's strategy as a **proposal** until adopted by GPTI's board.
- Use `governance/status-register.md` for the current public status of formation, IRS, programme and partner claims.
- All numbers require source, date, scope, method and approver. No invented outcomes or logos.
- GPTI retains independent public interest decision making. A commercial Climate Passport entity, if involved, requires disclosed ownership, fair terms, conflict review and a written agreement before benefits flow either way.
- Separate public copy from internal editorial, legal or development notes.
- Bilingual pages use equivalent meaning; do not machine publish unreviewed translations.

## Change workflow

Propose a decision in `governance/decision-log.md`; revise Markdown source; have a content owner check factual status and partner names; update Word/Web outputs; run relevant QA; record commit and date. Put confidential contracts, personal identifiers, bank data and minors' information outside this repository.
