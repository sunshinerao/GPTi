# GPTi repository and publication

The canonical GitHub repository is [`sunshinerao/GPTi`](https://github.com/sunshinerao/GPTi), created as **private** on 2026-09-26. `main` contains the founding strategy, brand, programme, website and operations sources. Private status is intentional while the dated incorporation manual and governance drafts are under review.

## Working locally

Clone with GitHub's normal SSH authentication:

```bash
git clone git@github.com:sunshinerao/GPTi.git
cd GPTi
```

Read `AGENTS.md`, `standards.lock.md` and `governance/status-register.md` before changing copy or code. Authoritative strategy and brand source is Markdown; the formatted Word copy is a review deliverable. Record new board decisions in `governance/decision-log.md` and verify regulatory facts at the time of filing.

The archived operations manual is a dated working reference. A file in this repository does not prove incorporation, IRS recognition, a partnership or UN consultative status.
